# youtube-clone
A responsive YouTube Clone built using HTML and CSS. This project recreates the YouTube homepage layout with a clean and modern user interface.

## Live Demo

https://techchirag1098.github.io/youtube-clone/

## Features

* Responsive Layout
* YouTube-inspired User Interface
* Sidebar Navigation
* Video Grid Layout
* Search Bar Design
* Channel Profile Section
* Video Thumbnails and Metadata

## Technologies Used

* HTML5
* CSS3
